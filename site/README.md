# Сайт «Истории Финтаксы»

Статический сайт о таксе Финтаксе: главная, список историй, страница истории и «О Финтаксе».
Ничего устанавливать не нужно — откройте `index.html` в браузере.

## Структура

```
site/
├── index.html          # весь сайт (разделы переключаются по хешу #/…)
├── artifact.html       # версия для публикации артефактом (генерируется)
├── build.py            # картинки для веба + сборка artifact.html
└── assets/
    ├── style.css       # оформление, светлая и тёмная темы
    ├── script.js       # простая навигация между разделами
    └── img/            # оптимизированные картинки (WebP)
```

Адреса разделов:

- `index.html` — главная
- `index.html#/stories` — все истории
- `index.html#/about` — о Финтаксе
- `index.html#/story/kak-taksa-stala-fintaksоy` — первая история
- `index.html#/story/nalogi-ne-strashno` — вторая история («Налоги — это не страшно»)

## Как добавить новую историю

1. Положить иллюстрацию в `../images/` и добавить её экспорт в `build.py`
   (функция `export_webp`), затем запустить:

   ```
   python site/build.py
   ```

2. В `index.html` добавить новый блок `<div class="view" data-view="story" id="view-story-2">`
   по образцу первой истории.
3. Добавить карточку истории на главной (`story-card`) и в списке (`story-row`).
4. В `assets/script.js` дописать название раздела в `VIEWS` и `TITLES`,
   а в `parseHash()` учитывать новый идентификатор.

## Публикация

- **Локально:** просто открыть `index.html`.
- **Артефакт claude.ai:** нужен вход в claude.ai (не через `ANTHROPIC_AUTH_TOKEN`);
  публикуется `artifact.html` вместе с папкой `assets/`.
- **Хостинг:** папку `site/` можно выложить на любой статический хостинг
  (GitHub Pages, Netlify, Reg.ru) — сайт не требует сервера.
