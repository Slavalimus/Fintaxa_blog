# 🐶 FinTaxa — финансы и налоги простым языком

**FinTaxa** — просветительский блог о финансах и налогах для обычных людей.
Главный герой и маскот — такса **Финтакса**, которая объясняет сложные
налоговые темы понятно, дружелюбно и без канцелярита.

## 📢 Где нас читать

- **Telegram:** [@fintaxa_explains](https://t.me/fintaxa_explains)
- **ВКонтакте:** сообщество [«Финтакса»](https://vk.com/wall-242737346)
- **Сайт:** статический сайт с историями (см. папку [`site/`](site/README.md))

## 📁 Структура репозитория

```
Fintaxa/
├── source/       # исходные статьи (большие материалы)
├── drafts/       # черновики постов и историй
├── posts/        # готовые посты для Telegram и VK
├── published/    # журнал публикаций (JSON-отчёты: кто, что, когда)
├── scripts/      # скрипты публикации (PowerShell, Python)
├── site/         # статический сайт «Истории Финтаксы»
├── images/       # иллюстрации с таксой Финтаксой
├── config/       # конфигурация платформ (секреты НЕ публикуются!)
└── .claude/      # агенты Claude Code для конвейера публикаций
```

## ⚙️ Конвейер публикаций

Каждый материал проходит путь:

```
source/ → drafts/ → posts/ → 🚀 публикация → published/
статья → черновик → готовые посты → Telegram + VK + сайт → журнал
```

Публикацией управляют агенты Claude Code из папки `.claude/agents/`:

| Агент            | Что делает                                   |
|------------------|----------------------------------------------|
| `tg-publisher`   | Публикует пост в Telegram-канал              |
| `vk-publisher`   | Публикует пост на стену сообщества ВК        |
| `vk-photo`       | Загружает фото в сообщество ВК               |
| `site-publisher` | Добавляет историю на сайт и пересобирает его |

## 🔐 Конфигурация и секреты

Токены и ключи лежат в `config/*.secure.json` и **не попадают в репозиторий**
(см. `.gitignore`). Чтобы развернуть проект у себя:

1. Скопируйте `config/telegram.example.json` → `config/telegram.secure.json`
   и вставьте токен своего бота.
2. Скопируйте `config/vk.example.json` → `config/vk.secure.json`
   и вставьте токен сообщества VK.
